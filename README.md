    English:       
The comments and game are in Czech!

My first Python game made in Pygame, i didnt use AI for this one (Just tutorials, forums and documentation). Its a short 2D builder game, where you build buildings to build more buildings, untill you build all buildings. About 8 minutes of playtime. If you want to run the sourcecode, you need pygame 2.6.1 (SDL 2.28.4, Python 3.10.11) and also pyinstaller if you want to compile.  The whole game can be compiled by running:

    pyinstaller --onefile --windowed --icon=Lavamine.ico --add-data "assets;assets" --add-data "sound;sound" Lavamine_main.py 
in powershell in the folder, where Lavamine_main.py is.
